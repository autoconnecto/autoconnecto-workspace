## NEW-2: profile create returned 500 (fixed during this run)

- At first, `POST /api/device-profiles` returned 500 for every body, including the UI "Create Device Profile".
- The cause was the F-09 duplicate-name query. It used column `name`, but the table column is `profile_name`.
- After Cursor's fix I re-tested:
  - API create returned 201 (`QA-A178L-Prof1`).
  - UI create worked (`QA-A178L-Prof2`).
  - F-09 duplicate names (exact, different case, padded spaces) return 400 "A profile with this name already exists", and the UI shows the same toast.
  - The items that had been blocked (F-24, F-28, F-32, F-33, F-18 profile parts) were then run.
- **Result: FIXED.** The failed attempts left undeletable audit rows.
