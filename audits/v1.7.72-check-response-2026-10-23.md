3. **SDK token in logs** — `Logger::redactSecrets` masks `devices/{token}/…` → `devices/***/…` on INFO/WARN/ERROR.
4. **OfflineBuffer timestamps** — NTP (`pool.ntp.org`) before queue; skip enqueue until wall clock exists (no 1970).
5. **Switch clip** — default `h: 11` / `desktopMinRows: 11`, wider `w: 12`; compact feedback drops SHARED/CLIENT lines; overflow hidden.
6. **Create Device toast** — `Promise.allSettled`; toast only if profiles fail; other failures logged without blocking the form.
7. **OTA rollout RUNNING** — on device terminal status (`UPDATED`/`FAILED`/`CANCELLED`), `OtaRolloutService.onDeviceTerminalStatus` runs `tickOne` immediately.
