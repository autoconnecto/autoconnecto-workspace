1. What you received

This pilot connects a machine press to Autoconnecto so you can:

  • See live electrical load and count product cycles
  • Let operators Start / End shift and record jobs from a phone (Bluetooth)
  • Track efficiency, worker activity, and optional tool life
  • Manage machines from the Factory Floor cloud dashboard

2. What this pilot includes

  • Live amps / volts / power when the machine is online
  • Electrical load cycles for Day / Week / Month / Year
  • Worker jobs from the phone + / − buttons
  • This login vs period totals
  • Efficiency when expected cycles/hour is configured
  • Optional tool life (blocks machine at the job limit)
  • Admin clear / reset of counters on the Wi‑Fi board from the cloud
  • Remote firmware update (OTA) for the Wi‑Fi board only
Pilot limits
BLE board firmware is not updated over the air (USB / visit if needed). Shop Wi‑Fi must match the network programmed into the Wi‑Fi board. Worker app is Android. Treat this as assisted production visibility — escalate issues to your Autoconnecto contact.

3. On-site checklist

  1. Machine panel powered; both ESP boards powered.
  2. Shop Wi‑Fi matches the network programmed on the device.
  3. Dashboard shows the machine online (Factory Floor → Machines).
  4. Physical label matches Bluetooth name (AC-001, AC-007, …).
  5. Android phone has Autoconnecto Worker installed (Bluetooth + Location allowed).
  6. Supervisor can open Factory Floor → Setup.

4. Worker phone app (operators)

Install

From the Autoconnecto web app (logged in): top bar → Worker app, or use the APK from your Autoconnecto contact. Allow Bluetooth, Location, and Nearby devices if prompted.

First-time setup

  1. Enter Worker ID and Name (kept until Edit profile).
  2. Scan and pin your machine AC-### (kept until Change machine).
  3. Stand within about 2 m while scanning if the press does not appear.

Shift

ActionResult
START SESSION / RESUME SESSIONBegins or resumes your session on the machine
+ / −Adds or removes a worker job for this shift
End shiftEnds session; machine pin stays
Change machineUnpin so you can select another press
Only one active operator at a time. If the app says the tool limit is reached, ask a supervisor to replace the tool and reset tool life in Setup.

Open Autoconnecto → dashboard containing the Factory Floor widget.

Periods: Day / Week / Month / Year (India Standard Time; weeks start Monday 00:00 IST).

Note: Efficiency uses electrical load cycles while someone is logged in — not the job buttons.

Cycle shapes: 2-level = Off → On load → Off · 3-level = On → On load → On.

6. Setup (tenant admin / owner)

  • Create or Link machines; set display name, thresholds, expected cycles/hour, tool life.
  • Each machine gets a code and Bluetooth name AC-###.
  • Reset tool life — after physical tool change (admin only).
  • Clear data & reset ESP — zeros period counters and Wi‑Fi board lifetime (admin only). Prefer End shift first. Does not change tool life. Cannot be undone.

9. Safety

  • Electrical / SSR work must be done by a qualified electrician.
  • Plant lockout/tagout and local safety rules still apply.
  • Do not share device tokens or admin passwords.

10. Quick cards

Operator

  1. Open Worker app → confirm name.
  2. Confirm pinned AC-###.
  3. START SESSION → work → + jobs as trained.
  4. End shift when done.

Supervisor

  1. Factory Floor → Machines.
  2. Check online / cycles / jobs.
  3. Tool expired → Reset tool life.
  4. Clean counters → End shift → Clear data & reset ESP.

11. Support

  • Approximate time of the issue
  • What you saw on the phone and dashboard
